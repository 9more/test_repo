# Imoh AI Portfolio

## About

Imoh is a data scientist and AI developer interested in
machine learning, artificial intelligence and data analysis.

## Spam Detection

The spam detection project classifies emails as either spam
or not spam.

The project uses spaCy for natural language preprocessing.
TF-IDF is used to convert text into numerical features.
LinearSVC is used as the classification algorithm.

The trained model is saved and exposed through a Flask API.

## Sentiment Analysis

The sentiment analysis project analyses text and determines
the sentiment expressed in the text.

The system uses natural language processing techniques
to preprocess the text before making predictions.

## Medical Insurance

The medical insurance project predicts medical insurance
charges based on information about an individual.

The model uses a Random Forest regression approach.

Categorical variables are encoded and numerical variables
are scaled before being passed to the model.

## Insurance Risk Classification

The insurance risk classification project predicts the
risk category associated with an insurance customer.

The model uses Logistic Regression with preprocessing
performed using a scikit-learn pipeline.

## Portfolio Architecture

The portfolio uses React for the frontend and Flask for
the backend.

The frontend communicates with the backend through HTTP
API requests.

The machine learning models are loaded by the Flask
backend and exposed through API endpoints.
