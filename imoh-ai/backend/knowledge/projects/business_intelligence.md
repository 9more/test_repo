## Technical Implementation

The project begins with extracting data from a relational SQL database before performing data cleaning and transformation using Power Query.

The cleaned data is modelled using a dimensional star schema consisting of fact and dimension tables to improve analytical performance and simplify report development.

Business metrics are implemented using DAX calculated columns and measures, allowing dynamic calculation of KPIs such as sales performance, profitability, customer behaviour and operational trends.

Interactive dashboards are then created in Power BI, enabling users to explore the data through filters, slicers and visualisations that support informed business decision making.

---

## Challenges & Solutions

### Data Quality

Raw datasets often contained inconsistencies, missing values and formatting issues. Power Query was used to clean and standardise the data before modelling.

### Efficient Data Modelling

To improve report performance and maintainability, a star schema was implemented using separate fact and dimension tables rather than a single flat dataset.

### Business Metrics

Rather than relying solely on imported fields, DAX measures and calculated columns were developed to create reusable business metrics that update dynamically based on user interaction.
